# 股息率全景表

股息 ÷ 目标股息率 = 买价，一眼看清每只票的买卖档位。

## 特点

- **股息率网格**：按目标股息率自动换算买卖价，8~16 档可选
- **BOLL 轨道**：日 / 周 / 月三周期，前复权口径，含当日正在走的那根
- **买卖计划与记账**：每档填股数，自动算成本、市值、盈亏（摊薄成本口径，与券商 App 一致）
- **累计分红**：分红质量列里显示近 12 年每股分红合计
- **按除息日算分红**：用东方财富的分红明细（含每次除权除息日）判断「买入后到底赶没赶上这次分红」，除息日当天买入的不算
- **红利税自动计算**：卖出时按先进先出匹配买入批次，持股 ≤1 个月 20%、1 个月～1 年 10%、超过 1 年 0%，税额从分红里扣掉，可直接和券商流水的「红利税」对照
- **含息盈亏**：把持有期间实际到手的净分红算进总盈亏，可与券商口径（不含分红）一键切换
- **两种成本口径**：摊薄成本（分红不冲减）/ 分红冲减成本（多数券商 App 的成本价），设置里一键切换；持仓弹窗里有「成本对账」，把成本拆成 累计买入 − 累计卖出 − 税后分红，跟券商逐行对
- **ETF 买卖计划**：价格自己填，8 档梯度，T+0 记账
- **云端同步**：数据存进你自己的 GitHub 私密 Gist，换设备也能拿回来

## 数据存在哪

网页本身是公开的静态页面，**不含任何你的数据**。

表格、持仓、买卖计划保存在两处：

1. 本机浏览器 localStorage（离线可用）
2. 你自己的 **GitHub 私密 Gist**（只有持有你令牌的人能读）

行情价格每次打开现取（腾讯 / 新浪 / 东方财富公开接口），不写进云端。

## 开启云端同步

1. 页面右上角点「同步」
2. 填一个 GitHub Personal access token（勾选 `gist` 权限即可）
3. 连接后自动创建私密 Gist，之后改动约 4 秒自动上传

连上之后，右上角「同步」旁边多一个 **⬆ 上传** 按钮：主页面直接点一下就是立即上传，
按钮会显示「上传中 → 已上传」，鼠标停留能看到上次同步时间，不用再打开弹窗。

换设备时点「从云端恢复」即可拿回全部资料。

## 成本价和券商 App 对不上？

券商 App 上的「成本价」多数是**分红冲减后**的成本：

```
摊薄成本价 = (累计买入含费用 − 累计卖出已扣费) ÷ 持仓股数
券商成本价 = (摊薄成本 − 持有期税后净分红) ÷ 持仓股数
```

所以拿高分红股（比如中远海控）一比，券商成本会明显更低，差额正好是每股分红。

页面默认用摊薄口径。点「持仓成本·盈亏」单元格打开详情，在**成本对账**里能看到两个成本价的完整推导，
右下角按钮直接切到「分红冲减口径」，表格和汇总立即跟着变。

两个数都对不上，通常是成交记录缺了某笔卖出 —— 少录一笔卖出，成本就会偏高。

对账块底部还有**数据体检**，会自动指出：卖出股数超过当时持仓、卖出时账户里没股票（漏录买入）、
成交记录没填费用、分红还在按年度估算（需重抓明细）等情况，逐条排查即可。
